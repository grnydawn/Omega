# OMEGA CMake Build System Refactoring Plan

This document outlines the refactoring plan for the OMEGA CMake build system. The guiding principle is to **strictly follow E3SM's build system** while maintaining a clean and minimal CMake structure.

## Design Philosophy

### Core Principles

1. **Strict E3SM Build System Alignment**: Omega is a component of E3SM. Rather than reinventing build configurations, Omega should leverage E3SM's mature build system wherever possible.

2. **E3SM Case as Configuration Source**: Create a simple E3SM case in the Omega build directory and use its output files for:
   - Environment settings (compilers, flags, modules)
   - MPI/job launch configurations
   - Machine-specific settings

3. **GLOB_RECURSE for Source Files**: Use `file(GLOB_RECURSE ... CONFIGURE_DEPENDS ...)` to automatically pick up new source files. This reduces maintenance overhead—developers can add new `.cpp` files without manually updating CMakeLists.txt.

4. **Minimal CMake File Splitting**: While splitting monolithic CMake files improves maintainability, keep the structure minimal. Only split when a clear separation of concerns justifies it.

### Rationale for E3SM Case Approach

Creating an E3SM case provides several benefits:

- **Consistency**: The case is generated by E3SM's build configuration (CIME), guaranteeing correct settings for each machine/compiler combination.
- **Safety**: Omega reuses proven configurations rather than attempting to replicate E3SM's complex machine detection logic.
- **Maintenance**: When E3SM updates its build system, Omega automatically benefits by regenerating the case.
- **Job Launch**: E3SM cases include machine-specific job launch scripts (SLURM, PBS, etc.) that Omega can reuse directly.

## E3SM Integration Strategy

### Overview

Instead of duplicating E3SM's complex machine detection and compiler configuration logic, Omega creates a minimal E3SM case and extracts the necessary build settings from its output files.

```
┌─────────────────────────────────────────────────────────────────────┐
│                     Omega Build Process                             │
├─────────────────────────────────────────────────────────────────────┤
│  1. User specifies E3SM source directory                            │
│                           ↓                                         │
│  2. Omega creates a minimal E3SM case in build directory            │
│     (./create_newcase --case omega_e3sm_case --compset ... )        │
│                           ↓                                         │
│  3. Run case.setup to generate environment files                    │
│     (.env_mach_specific.sh, .case.run, etc.)                        │
│                           ↓                                         │
│  4. Omega CMake extracts settings from these files:                 │
│     - Compiler paths and flags                                      │
│     - MPI configuration                                             │
│     - Module load commands                                          │
│     - Job launch parameters                                         │
│                           ↓                                         │
│  5. Build Omega using extracted E3SM settings                       │
└─────────────────────────────────────────────────────────────────────┘
```

### E3SM Case Files Used

| File | Purpose |
|------|---------|
| `.env_mach_specific.sh` | Environment variables, module loads, compiler paths |
| `.case.run` | MPI launch command and arguments (-n, -N, -c flags) |
| `env_build.xml` | Build configuration (DEBUG, compiler, machine) |
| `env_mach_pes.xml` | PE layout configuration |
| `Macros.cmake` | CMake variables for compilers, flags |

### Benefits Over Custom Detection

| Aspect | Custom Detection | E3SM Case Approach |
|--------|------------------|-------------------|
| Machine support | Must maintain machine configs | Inherits all E3SM machines |
| Compiler flags | May diverge from E3SM | Guaranteed consistency |
| Job launch | Must parse multiple formats | Reuse existing scripts |
| Module loads | Complex logic per machine | Already resolved |
| Maintenance | Omega team maintains | E3SM team maintains |

## Identified Problems

### Problem 1: OmegaBuild.cmake is a Monolithic File

**Location**: `cmake/OmegaBuild.cmake` (741 lines)

**Issue**: Single file contains multiple unrelated concerns:
- Variable declarations
- Compiler detection
- MPI configuration extraction
- Shell script generation
- Build configuration logic

**Solution**: Minimal splitting into 2-3 focused modules (not 7+ as previously suggested).

### Problem 2: Deprecated CMake Patterns

#### 2a. Direct CMAKE_CXX_FLAGS Manipulation

**Current Pattern**:
```cmake
set(CMAKE_CXX_FLAGS "${CMAKE_CXX_FLAGS} ${OMEGA_CXX_FLAGS}")
```

**Solution**:
```cmake
add_compile_options(${OMEGA_CXX_FLAGS})
# Or target-specific:
target_compile_options(OmegaLib PRIVATE ${OMEGA_CXX_FLAGS})
```

#### 2b. Global add_definitions() Usage

**Current Pattern**:
```cmake
add_definitions(-DOMEGA_DEBUG)
```

**Solution**:
```cmake
target_compile_definitions(OmegaLib PRIVATE OMEGA_DEBUG)
```

### Problem 3: Redundant Compiler Detection

**Issue**: Omega parses compiler `--version` output to detect architecture, duplicating logic that E3SM already handles.

**Solution**: Extract architecture and compiler settings from the E3SM case's `Macros.cmake` or `env_build.xml`.

### Problem 4: Repetitive Test Registration

**Location**: `test/CMakeLists.txt` (496 lines)

**Current Pattern**:
```cmake
add_omega_test(DATA_TYPES_TEST testDataTypes.exe base/DataTypesTest.cpp "-n;1")
add_omega_test(MACHINE_ENV_TEST testMachEnv.exe base/MachEnvTest.cpp "-n;8")
# ... 38 more nearly identical lines
```

**Solution**: Data-driven test registration with a single loop.

### Problem 5: Manual Script Generation

**Issue**: Shell scripts generated via 40+ `file(APPEND)` calls.

**Solution**: Use `configure_file()` with templates.

## Phase 1: Clean Up Current Build System

### Task 1.1: Minimal CMake Module Split

Create a focused split—only where it significantly improves clarity:

```
cmake/
├── OmegaBuild.cmake        # Main macros (~200 lines)
├── OmegaE3SMCase.cmake     # E3SM case creation and parsing (~150 lines)
├── OmegaScripts.cmake      # Script generation with templates (~100 lines)
└── FindParmetis.cmake      # Keep existing
```

**New OmegaBuild.cmake structure**:
```cmake
# cmake/OmegaBuild.cmake - Main build macros

include(${CMAKE_CURRENT_LIST_DIR}/OmegaE3SMCase.cmake)

# Variable declarations
set(OMEGA_PROJECT_NAME "OmegaOceanModel")

# Build mode options
set(OMEGA_BUILD_MODES "E3SM" "STANDALONE" "NOT_DEFINED")

# Architecture options
set(OMEGA_ARCH_OPTIONS "CUDA" "HIP" "OPENMP" "SYCL" "SERIAL")
set(OMEGA_ARCH "" CACHE STRING "Target architecture")

# Main macros
macro(setup_common)
    # ... existing logic
endmacro()

macro(init_standalone_build)
    omega_create_e3sm_case()
    omega_extract_e3sm_settings()
    omega_generate_scripts()
endmacro()
```

### Task 1.2: Replace Deprecated CMake Patterns

**Replace add_definitions()**:
```cmake
# Before:

# After:
target_compile_definitions(OmegaLib PRIVATE
    $<$<BOOL:${OMEGA_DEBUG}>:OMEGA_DEBUG>
    OMEGA_LOG_LEVEL=${OMEGA_LOG_LEVEL}

```

**Replace CMAKE_CXX_FLAGS manipulation**:
```cmake
# Before:

# After:

```

### Task 1.3: Data-Driven Test Registration

**New test/CMakeLists.txt** (~80 lines instead of 496):
```cmake
# Test data: NAME;EXECUTABLE;SOURCE;MPI_ARGS
set(OMEGA_UNIT_TESTS
    # Base tests
    "DATA_TYPES_TEST;testDataTypes.exe;base/DataTypesTest.cpp;-n;1"
    "MACHINE_ENV_TEST;testMachEnv.exe;base/MachEnvTest.cpp;-n;8"
    "BROADCAST_TEST;testBroadcast.exe;base/BroadcastTest.cpp;-n;8"
    "HALO_TEST;testHalo.exe;base/HaloTest.cpp;-n;4"

    # Infra tests
    "LOGGING_TEST;testLogging.exe;infra/LoggingTest.cpp;-n;1"
    "CONFIG_TEST;testConfig.exe;infra/ConfigTest.cpp;-n;1"
    "IO_TEST;testIO.exe;infra/IOTest.cpp;-n;4"

    # Add remaining tests...
)

# Register all tests via loop
foreach(test_spec ${OMEGA_UNIT_TESTS})
    string(REPLACE ";" ";" test_parts "${test_spec}")
    list(GET test_parts 0 test_name)
    list(GET test_parts 1 test_exe)
    list(GET test_parts 2 test_src)
    list(SUBLIST test_parts 3 -1 test_mpi_args)

    add_omega_test(${test_name} ${test_exe} ${test_src} "${test_mpi_args}")
endforeach()
```

### Task 1.4: Keep GLOB_RECURSE for Source Files

**Rationale**: GLOB_RECURSE with CONFIGURE_DEPENDS is preferred for maintenance convenience. When developers add new source files, they don't need to manually update CMakeLists.txt.

**src/CMakeLists.txt**:
```cmake
# Automatically collect source files - new files are picked up on cmake reconfigure
file(GLOB_RECURSE _LIBSRC_FILES CONFIGURE_DEPENDS
    ${CMAKE_CURRENT_SOURCE_DIR}/infra/*.cpp
    ${CMAKE_CURRENT_SOURCE_DIR}/base/*.cpp
    ${CMAKE_CURRENT_SOURCE_DIR}/ocn/*.cpp
    ${CMAKE_CURRENT_SOURCE_DIR}/timeStepping/*.cpp
)

# Note: CONFIGURE_DEPENDS causes cmake to re-run when files are added/removed
# This is the intended behavior for development convenience
```

## Phase 2: E3SM Case-Based Integration

### Task 2.1: E3SM Case Creation Module

**cmake/OmegaE3SMCase.cmake**:
```cmake
# E3SM Case-Based Configuration Module
# Creates a minimal E3SM case to extract build settings

set(OMEGA_E3SM_CASE_NAME "omega_e3sm_config" CACHE STRING "Name for the E3SM configuration case")

#------------------------------------------------------------------------------
# Create a minimal E3SM case for configuration extraction
#------------------------------------------------------------------------------
function(omega_create_e3sm_case)
    if(NOT E3SM_SOURCE_DIR)
        message(FATAL_ERROR "E3SM_SOURCE_DIR must be set for standalone build")
    endif()

    set(CIME_ROOT "${E3SM_SOURCE_DIR}/cime")
    set(CASE_DIR "${OMEGA_BUILD_DIR}/${OMEGA_E3SM_CASE_NAME}")

    # Check if case already exists
    if(EXISTS "${CASE_DIR}/env_build.xml")
        message(STATUS "Using existing E3SM case: ${CASE_DIR}")
        set(OMEGA_E3SM_CASE_DIR "${CASE_DIR}" PARENT_SCOPE)
        return()
    endif()

    message(STATUS "Creating E3SM case for configuration extraction...")

    # Create minimal case
    # Use a simple compset that doesn't require heavy dependencies
    execute_process(
        COMMAND ${CIME_ROOT}/scripts/create_newcase
            --case ${CASE_DIR}
            --compset OMEGA_STUB
            --res T62_oQU120
            --machine ${OMEGA_MACHINE}
            --project ${OMEGA_PROJECT}
        RESULT_VARIABLE _result
        OUTPUT_VARIABLE _output
        ERROR_VARIABLE _error
    )

    if(NOT _result EQUAL 0)
        message(FATAL_ERROR "Failed to create E3SM case: ${_error}")
    endif()

    # Run case.setup to generate environment files
    execute_process(
        COMMAND ${CASE_DIR}/case.setup
        WORKING_DIRECTORY ${CASE_DIR}
        RESULT_VARIABLE _result
    )

    if(NOT _result EQUAL 0)
        message(FATAL_ERROR "Failed to setup E3SM case")
    endif()

    set(OMEGA_E3SM_CASE_DIR "${CASE_DIR}" PARENT_SCOPE)
    message(STATUS "E3SM case created: ${CASE_DIR}")
endfunction()

#------------------------------------------------------------------------------
# Extract build settings from E3SM case
#------------------------------------------------------------------------------
function(omega_extract_e3sm_settings)
    if(NOT OMEGA_E3SM_CASE_DIR)
        message(FATAL_ERROR "OMEGA_E3SM_CASE_DIR not set. Run omega_create_e3sm_case first.")
    endif()

    set(CASE_DIR ${OMEGA_E3SM_CASE_DIR})

    # Read Macros.cmake generated by CIME
    if(EXISTS "${CASE_DIR}/Macros.cmake")
        include("${CASE_DIR}/Macros.cmake")
        message(STATUS "Loaded E3SM Macros.cmake")
    endif()

    # Extract compiler settings from env_build.xml
    omega_xmlquery("COMPILER" _compiler)
    omega_xmlquery("DEBUG" _debug)
    omega_xmlquery("MPILIB" _mpilib)

    # Set OMEGA variables from E3SM case
    if(_compiler)
        set(OMEGA_COMPILER "${_compiler}" PARENT_SCOPE)
    endif()

    if(_debug STREQUAL "TRUE")
        set(OMEGA_BUILD_TYPE "Debug" PARENT_SCOPE)
    else()
        set(OMEGA_BUILD_TYPE "Release" PARENT_SCOPE)
    endif()

    # Extract MPI launch configuration from .case.run
    omega_extract_mpi_config()

    message(STATUS "E3SM settings extracted:")
    message(STATUS "  Compiler: ${_compiler}")
    message(STATUS "  Debug: ${_debug}")
    message(STATUS "  MPI: ${_mpilib}")
endfunction()

#------------------------------------------------------------------------------
# Helper: Query CIME XML
#------------------------------------------------------------------------------
function(omega_xmlquery VARNAME OUTPUT_VAR)
    execute_process(
        COMMAND ${OMEGA_CIME_ROOT}/CIME/Tools/xmlquery
            --caseroot ${OMEGA_E3SM_CASE_DIR}
            --value ${VARNAME}
        OUTPUT_VARIABLE _output
        OUTPUT_STRIP_TRAILING_WHITESPACE
        RESULT_VARIABLE _result
    )
    if(_result EQUAL 0)
        set(${OUTPUT_VAR} "${_output}" PARENT_SCOPE)
    endif()
endfunction()

#------------------------------------------------------------------------------
# Extract MPI configuration from case run script
#------------------------------------------------------------------------------
function(omega_extract_mpi_config)
    set(CASE_RUN "${OMEGA_E3SM_CASE_DIR}/.case.run")
    if(NOT EXISTS "${CASE_RUN}")
        message(WARNING "No .case.run found, using default MPI settings")
        return()
    endif()

    file(READ "${CASE_RUN}" _content)

    # Extract MPI arguments (this is machine-specific in E3SM)
    # The case.run script contains the correct mpiexec invocation
    string(REGEX MATCH "mpiexec[^\n]*" _mpi_line "${_content}")
    if(_mpi_line)
        set(OMEGA_MPI_EXEC_LINE "${_mpi_line}" PARENT_SCOPE)
    endif()
endfunction()
```

### Task 2.3: Architecture Detection via E3SM

Instead of parsing compiler `--version` output, extract architecture from E3SM case:

```cmake
function(omega_detect_architecture_from_e3sm)
    # Query GPU_TYPE and GPU_OFFLOAD from E3SM case
    omega_xmlquery("GPU_TYPE" _gpu_type)
    omega_xmlquery("GPU_OFFLOAD" _gpu_offload)

    if(_gpu_offload STREQUAL "cuda")
        set(OMEGA_ARCH "CUDA" PARENT_SCOPE)
    elseif(_gpu_offload STREQUAL "hip")
        set(OMEGA_ARCH "HIP" PARENT_SCOPE)
    elseif(_gpu_offload STREQUAL "sycl")
        set(OMEGA_ARCH "SYCL" PARENT_SCOPE)
    else()
        # Check for OpenMP
        omega_xmlquery("BUILD_THREADED" _threaded)
        if(_threaded STREQUAL "TRUE")
            set(OMEGA_ARCH "OPENMP" PARENT_SCOPE)
        else()
            set(OMEGA_ARCH "SERIAL" PARENT_SCOPE)
        endif()
    endif()

    message(STATUS "Architecture from E3SM case: ${OMEGA_ARCH}")
endfunction()
```

## Summary

This refactoring plan prioritizes:

1. **E3SM Alignment**: By creating an E3SM case, Omega inherits all of E3SM's machine support, compiler configurations, and job launch logic without duplication.

2. **Maintenance Convenience**: GLOB_RECURSE with CONFIGURE_DEPENDS eliminates the need to manually update source file lists.

3. **Minimal Complexity**: The CMake structure is split only where it provides clear value (E3SM case handling, script generation), avoiding over-engineering.

The result is a build system that is both simpler to maintain and more tightly integrated with E3SM's proven infrastructure.
